# ice-cream-sales-linear-regression
Simple Linear Regression model to predict ice cream sales based on temperature

## 🎯 Objective
To understand how temperature affects ice cream sales
To build a predictive model using linear regression


## 📂 Dataset

The dataset contains the following features:

Temperature (Independent Variable)

Ice Cream Sales (Dependent Variable)


## 🔍 Steps Performed

### 1. Data Loading

Imported dataset using Pandas

### 2. Exploratory Data Analysis (EDA)

Visualized relationship using scatter plot

Identified positive correlation

### 3. Model Building

Applied Simple Linear Regression using Scikit-learn

### 4. Prediction

Predicted sales based on temperature

### 5. Visualization

Plotted regression line to compare actual vs predicted values

## 📊 Results & Insights

Found a strong positive relationship between temperature and sales

As temperature increases, ice cream sales also increase

Model performs well in capturing the trend
